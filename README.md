## ✨ What I Built & How
This portfolio isn't just a static page; it's a carefully engineered front-end experience. Here is how it was put together:

* **Core Foundation:** Scaffolded using Vite and React.js for extremely fast hot-module replacement and optimized production builds.
* **Scroll Architecture:** Implemented Lenis to override default browser scrolling, providing a buttery-smooth, fluid scrolling experience across all sections.
* **Animation Engine:** Integrated GSAP (GreenSock) alongside Framer Motion to handle complex, timeline-based entry animations, text reveals, and interactive component transitions.
* **Form Functionality:** Structured the contact section to support seamless messaging (integration via EmailJS planned/configured).
* **Production Deployment:** Connected the GitHub repository directly to Vercel for continuous integration. Every `git push` automatically triggers a fresh production build.
* **Custom Domain Networking:** Secured a `.me` domain via the GitHub Student Developer Pack and manually configured A and CNAME DNS records to route traffic from Namecheap to Vercel's edge network.

## 🛠️ Tech Stack
* **Frontend:** React.js, HTML5, CSS3
* **Build Tool:** Vite
* **Animations:** GSAP, Framer Motion
* **Scroll Management:** Lenis
* **Hosting & CI/CD:** Vercel
* **Domain Management:** Namecheap (GitHub Student Developer Pack)
